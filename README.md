# Data Analysis with Python

## Overview
This repository contains different python script for different analysis such as client level concurrence analysis, Data Quality check, Flatfile generation, waterfall analysis data analysis and many more using libraries such as pandas, regex, datetime etc.

## Acronymns definition
  - RADET: This refers to a report that contains all services offered to a number of patients, the date service was offered, result and date of results.
  - Centralsync: This is a database that houses different data report synced from implementing partner (IP) database(LAMIS).
  - NDR: This is a national data repository that houses data synced from implementing partner (IP) database(LAMIS) and create analysis out of them.
  - Indicator: This is used to measure program implementation
  - Flatfile: A report that results from IP RADET analysis or some analysis done in Centralsync or NDR.
